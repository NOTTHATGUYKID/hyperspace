# HYPERSPACE

Self-contained browser arcade and video library. Main site: https://silver-syrniki-793da6.netlify.app

index.html bundles the app JavaScript, CSS and catalog. Game and video content loads from its original providers. The local password screen is a casual UI lock, not secure authentication.

CDN: https://cdn.jsdelivr.net/gh/NOTTHATGUYKID/hyperspace@main/index.html

The bookmark replaces the current page. It is subject to CSP, CORS, browser and network restrictions. Loading on a different page does not change that page's origin. Feedback is sent only from the hosted Netlify site. No server credentials or email notification settings are included.

# HYPERSPACE

Self-contained arcade interface and complete catalog. Four games include their assets: 2048, Hextris, Snake and Paddle. Other games need external providers.

Updated mobile player, offline startup diagnostics, local-file retry and alternate-version recovery are included. This is not a network proxy; provider access and iPad compatibility are not guaranteed.

Game source, modifications and licenses: HYPERSPACE-offline-sources.zip.

Bookmark endpoint: https://cdn.bili33.top/gh/NOTTHATGUYKID/hyperspace@main/index.html

Upload these files to the existing repository main branch. A local build does not update GitHub or the mirror automatically.
